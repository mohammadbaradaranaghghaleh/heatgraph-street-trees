# Manuscript

Elsevier `elsarticle`, author-year, A4, written for *Landscape and Urban Planning*.

| File | Role |
|---|---|
| `main.tex` | source of truth |
| `main.pdf` | compiled manuscript (tectonic 0.17, XeTeX) |
| `main_flat.tex` | GENERATED by `flatten.py` (tables inlined); do not edit |
| `manuscript_blind.tex`, `.pdf` | GENERATED by `make_blind.py`: double-anonymised manuscript (no authors, affiliations, e-mail, CRediT or PDF author metadata; repository URL withheld) |
| `title_page.tex`, `.pdf` | GENERATED by `make_blind.py`: title, authors, affiliations, corresponding author, acknowledgements, CRediT, declarations, data and code availability |
| `highlights.txt` | 5 highlights, each ≤ 85 characters |
| `cover_letter.tex`, `.pdf` | cover letter to the Editors-in-Chief |
| `references.bib` | GENERATED by `build_bib.py` from Crossref/arXiv records; verification log in `bib_verification.json` |
| `facts.json` | GENERATED by `build_facts.py` from the saved results; every number in the text comes from here |
| `check_numbers.py` | structure + numeric audit (89 claims, sentence-anchored headline results, traceability of every number) |
| `figures/`, `tables/` | byte-identical copies of `../figures`, `../tables` (written by `scripts/10_figures_tables.py`) |

## Build and check (from `manuscript/`)

```powershell
& "$env:USERPROFILE\miniforge3\envs\tex\Library\bin\tectonic.exe" main.tex   # -> main.pdf
..\.venv\Scripts\python.exe flatten.py
..\.venv\Scripts\python.exe check_numbers.py
..\.venv\Scripts\python.exe make_blind.py                                     # -> manuscript_blind.tex, title_page.tex
& "$env:USERPROFILE\miniforge3\envs\tex\Library\bin\tectonic.exe" manuscript_blind.tex
& "$env:USERPROFILE\miniforge3\envs\tex\Library\bin\tectonic.exe" title_page.tex
& "$env:USERPROFILE\miniforge3\envs\tex\Library\bin\tectonic.exe" cover_letter.tex
```

`make_blind.py` stops with an error if any author name, the e-mail, the affiliation or the repository URL
is left in the blind source. Re-run it after every change to `main.tex`.

The TeX engine is tectonic from conda-forge (`conda create -n tex -c conda-forge tectonic poppler`). It
fetches the LaTeX packages it needs on first use. The preamble also compiles with pdflatex + BibTeX
(Overleaf default): `iftex` selects `fontenc`/`inputenc` under pdflatex and `fontspec` under XeTeX.

To regenerate the LaTeX tables after a change in the results:
`..\.venv\Scripts\python.exe ..\scripts\10_figures_tables.py --tables-only`, then copy `../tables/*.tex` here.
CSV and Markdown versions keep the raw values; the LaTeX versions only typeset them (grouped headers,
proper minus signs, readable patch names).

## Double-anonymised upload

Upload `manuscript_blind.pdf` as the manuscript, `title_page.pdf` as the title page, `highlights.txt`,
`cover_letter.pdf`, and the figures. The repository URL contains an author's name, so it appears only on
the title page.

## Before submission

- Add the Zenodo DOI to "Data and code availability" when it exists; the text says the results archive will be released on publication.
- ORCIDs are not printed; enter them in the submission system.
- Check the journal's current Guide for Authors (review model, graphical abstract, word limit, keyword limit, reference style).
